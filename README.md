# 🚨 MontirSiaga.com
### *On-Demand Emergency Roadside Assistance Platform*
> **"Montir Datang, Panik Hilang"** — Solusi tanggap darurat mogok otomotif 1-Click Action.

---

## 📱 Tentang MontirSiaga.com
**MontirSiaga.com** adalah platform aplikasi web / mobile (PWA) tanggap darurat jalan raya yang menghubungkan pengendara yang mengalami kendala kendaraan (mobil/motor) dengan jaringan mitra bengkel dan montir independen terdekat secara instan dalam radius 5 km.

---

## ⚡ Fitur Unggulan

1. **🚨 1-Click SOS Action & Countdown Cepat**
   * Sekali pencet tombol SOS langsung mengunci titik koordinat GPS darurat dan menyiarkan sinyal pencarian ke mitra dalam radius 5 km.
   * Dilengkapi hitung mundur otomatis 3 detik untuk pemilihan preset kendala darurat.

2. **🛞 Preset Kendala Cepat**
   * 🛞 Ban Bocor / Kempes (Tambal ban & ganti ban cadangan)
   * ⚡ Mesin Mati & Jumper Aki Darurat
   * ⛽ Pengiriman BBM Darurat ke Lokasi
   * 🚛 Bantuan Derek / Towing Terdekat

3. **📡 Multi-Tier Geofencing Radar**
   * **Ring 1 (Radius 0 – 2,5 km):** Pencarian instan ke mitra montir terdekat (respon 15-30 detik).
   * **Ring 2 (Radius 2,6 – 5,0 km):** Perluasan radar otomatis jika Ring 1 sedang sibuk.
   * **Hotline Eskalasi Darurat:** Sambungan langsung ke derek resmi Jasa Marga **14080** dan bengkel resmi 24 jam.

4. **🔊 Sound Engine (Web Audio API)**
   * Efek audio sirene peringatan darurat saat SOS ditekan.
   * Beep timer per detik dan notifikasi chime saat montir terkonfirmasi.

5. **🤝 Onboarding & Verifikasi Kemitraan Montir (Two-Step Flow)**
   * Form pendaftaran mitra dengan bagi hasil transparan **80% Montir / 20% Platform**.
   * Upload pas foto profil montir asli.
   * Upload foto e-KTP dan sertifikasi resmi (NIB / BNSP Otomotif).
   * Sinkronisasi data mitra ke WhatsApp Admin (+62 8778 1047 453) dan penyimpanan lokal localStorage.

6. **👨‍🔧 Dual Mode (Mode Pengendara & Mode Mitra Montir)**
   * Pengendara dapat melacak posisi pergerakan montir secara real-time di peta Leaflet.
   * Mitra montir dapat menerima order masuk darurat lengkap dengan navigasi lokasi pemesan dan potensi pendapatan bersih.

---

## 🚀 Cara Menjalankan

1. **Jalankan via Windows Batch:**
   * Klik ganda pada file BUKA_MONTIRSIAGA.bat.
2. **Buka Langsung di Browser:**
   * Buka file index.html menggunakan browser modern (Chrome, Edge, Firefox, Safari).

---

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3 Modern (Mobile Shell Simulator), Vanilla JavaScript (ES6+)
* **Mapping:** Leaflet.js Interactive OpenStreetMap
* **Audio Engine:** Web Audio API (Synthesizer Oscillator & Gain Nodes)
* **Storage:** LocalStorage API & FileReader API untuk preview berkas upload
